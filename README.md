## 📌 Sobre o Projeto

A **Jornada do Respeito** é um aplicativo web e jogo de tabuleiro interativo desenvolvido para aproximar estudantes, educadores e famílias na prevenção e combate ao bullying e cyberbullying.

O projeto aborda **20 tipos de agressões e violências virtuais e presenciais**, transformando o aprendizado e a conscientização em uma experiência dinâmica, empática e gamificada.

### 🎯 Principais Objetivos
- **Educativo:** Apresentar de forma clara e acessível os conceitos e impactos de 20 formas de bullying e cyberbullying.
- **Gamificado:** Oferecer um jogo de tabuleiro interativo para 2 jogadores (ou duplas) que estimula o diálogo e o pensamento crítico.
- **Ponte Comunidade-Escola:** Facilitar a mediação entre jovens e educadores através de perguntas, respostas e desafios reflexivos durante as partidas.

## 💻 Como Executar o Projeto Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) (versão 18 ou superior)
- Gerenciador de pacotes `npm` ou `yarn`

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/heblingmec2022/BullyingGame.git
   cd BullyingGame

```

1. **Instale as dependências:**

```
npm install

```

1. **Inicie o servidor de desenvolvimento:**

```
npm run dev

```

1. **Acesse no navegador:** Abra o endereço indicado no terminal (geralmente `http://localhost:5173`).
